# AB Web Studio — página oficial

Página estática de AB Web Studio: páginas web con animación y pedidos por WhatsApp para negocios de toda Venezuela.

## Qué tiene

- Inicio con el cursor del logo (AB|) que escribe el título; al bajar, el cursor se estira hasta volverse la página blanca de las demos.
- Las tres demos (Sharp Society, Ceniza y Molar Studio) con videos reales de su recorrido en una laptop y un teléfono; el nombre de cada una se borra y se reescribe al cambiar.
- "Un toque, pedido escrito": un pedido de la página se convierte en un mensaje de WhatsApp.
- Planes con precio (Básico, Completo y A medida), proceso de 5 días, preguntas frecuentes y contacto.
- Cursor propio en computadora que se vuelve etiqueta sobre los enlaces.

Sin JavaScript o con movimiento reducido, todo el contenido queda visible y las demos se ven como tarjetas.

`the-barber-hub-demo/` es una demo privada aparte; no se enlaza desde esta página.

## Videos de las demos

`assets/demos/*.webm` se grabaron de las demos publicadas con Playwright y Chrome, y se comprimieron en VP9. Cada uno tiene su portada `.jpg`.
